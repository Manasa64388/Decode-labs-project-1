- Fetch API
- Python
- Flask
- SQLite
- REST API

**Features:**
- View projects
- Add projects
- Edit projects
- Delete projects
- Dynamic DOM updates
- API error handling
- Persistent database storage
- Frontend-backend communication

📁 `Project4/`
