# DecodeLabs Project 1 — Responsive Frontend Website

A responsive frontend website developed as part of my DecodeLabs Full Stack Development Internship.

This project focuses on building a responsive, accessible, and structured web interface using HTML5, CSS3, and JavaScript.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Semantic HTML structure
- Responsive mobile-first design
- CSS Grid and Flexbox
- Responsive navigation menu
- Fluid typography using `clamp()`
- Keyboard-accessible navigation
- Responsive layouts for mobile, tablet, and desktop
